¿Cómo levanto Ollama con Docker? 
docker run -d --name ollama -p 11434:11434 -e OLLAMA_ORIGINS=* -v ollama:/root/.ollama ollama/ollama
docker exec -it ollama ollama pull llama3.2

OLLAMA_ORIGINS debe permitir el sitio del frontend (http://localhost:4200); con * permite todos. Si ya tienes tu contenedor, solo pon aquí su dirección y el nombre exacto del modelo (ollama list). Si tu IA usa otro formato de API, se cambia en core/services/ollama.ts.
